# CodePulse

## Project Overview
CodePulse is a planned software house
management workspace.

It aims to organize company projects,
employees, meetings and daily operations.

## Target Audience
- Owner
- Managers and Team Leads
- Employees

## Website Pages
- Home
- About
- Modules
- Contact

## Planned Modules
- Company Dashboard
- Projects and Tasks
- Meetings and Calendar
- Employees and Departments
- Attendance and Leave
- Clients and CRM
- Finance and Invoices
- Notifications and Reports
- Roles and Permissions

## Technologies
- HTML
- CSS (upcoming stage)
- JavaScript (upcoming stage)
- Git
- GitHub

## Internship Progress
Week 1: Project selection,
planning and basic website structure.

## Current Limitations
This is an initial static website.
Authentication, database, real-time meetings,
and employee permissions are not implemented.
